Репозиторий содержит 5 лабораторных работ по курсу «Дискретный анализ». Каждая работа посвящена изучению классических алгоритмов, структур данных и инструментов анализа производительности. 🧩
🔍 Детальный анализ лабораторных работ
Lab 1: Bucket Sort (блочная сортировка)

Реализация алгоритма блочной сортировки для эффективной сортировки данных с равномерным распределением.

Основные возможности:

    Разбиение входного массива на корзины (buckets)

    Сортировка элементов внутри каждой корзины

    Объединение корзин в итоговый отсортированный массив

    Оценка сложности: средний случай O(n + k), худший O(n²)

Файлы:

    main.cpp

Тестирование:
Покрывает положительные, отрицательные значения, дубликаты, пустой массив и массив из одного элемента. Проверяется корректность сортировки и устойчивость.
Lab 2: AVL-дерево

Реализация самобалансирующегося бинарного дерева поиска (AVL-дерева) с поддержкой всех классических операций.

Основные возможности:

    Вставка с автоматической балансировкой (повороты LL, RR, LR, RL)

    Удаление узлов с восстановлением баланса

    Поиск элемента

    Обходы дерева (in-order, pre-order, post-order)

    Вычисление высоты и коэффициента баланса

Файлы:

    main.cpp

Тестирование:
Проверяются вставка/удаление, поддержание баланса, корректность обходов, граничные случаи (пустое дерево, один узел, вырожденные последовательности).

Lab 4: Строковые алгоритмы (Ахо-Корасик)

Реализация алгоритма Ахо-Корасик для поиска множества образцов в тексте за линейное время.

Основные возможности:

    Построение бора (trie) по набору образцов

    Построение суффиксных и терминальных ссылок

    Поиск всех вхождений образцов в тексте

    Обработка пересекающихся и вложенных образцов

Файлы:

    main.cpp

Тестирование:
Проверяется поиск одного и нескольких образцов, отсутствие вхождений, пересекающиеся образцы, граничные случаи (пустой текст, пустой образец).
Lab 5: Суффиксное дерево (статистика совпадений)

Построение суффиксного дерева и его применение для анализа повторяющихся подстрок.

Основные возможности:

    Построение суффиксного дерева (алгоритм Укконена)

    Поиск самой длинной повторяющейся подстроки

    Подсчёт статистики совпадений

    Поиск всех вхождений подстроки

Файлы:

    main.cpp

Тестирование:
Проверяется корректность построения, поиск повторяющихся подстрок, статистика совпадений, граничные случаи (односимвольная строка, строка без повторов).
⚙️ Технологический стек

    Язык программирования: C++ (современные стандарты: auto, unique_ptr, shared_ptr, move-семантика)

    Система сборки: CMake (компиляция через CMake Tools в VSCode)

    Фреймворк тестирования: Google Test

    Инструменты профилирования: Valgrind, gprof

Используемые технологии и подходы:

    Шаблоны (templates)

    Динамические структуры данных (деревья, бор)

    Рекурсивные и итеративные обходы

    Управление памятью (RAII, умные указатели)

    Профилирование и оптимизация
